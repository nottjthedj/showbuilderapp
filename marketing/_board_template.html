The engine

One rule makes the whole story work — and it's the same rule the final game runs on.

The vault takes four keys. Four colours, four turns, all inside the same minute. One key went to each family that built this city, fifty years ago, because none of them trusted the others.

That single rule answers every question the marketing has to answer: why they're all in one building (nobody opens it alone), why they team up and betray each other (every alliance is two crews who need a second key), and why you're there (a key gets a crew a turn — it doesn't get them the room, so all four are recruiting off the floor).

And it pays off for real: the last game of the night is a four-colour code. The campaign isn't describing the night — it's teaching people how to win it.
